| 目录 | 规格 | 用途 | 体积 |
|---|---|---|---|

- **水印**：右下角，宽约为图宽的 7.8%，边距约 2.6%。
  - 白线稿 + **柔和暗影**，所以深色照片上清晰。
  - **自适应**：先采样水印所在区域的平均亮度，若偏亮（> 110）就改用**深色线稿 + 浅色晕影**——否则白色线条会在亮底（如那张亮灰水泥地的马赛）上被背景吃掉。

## 三、怎么更新（加照片 / 改说明）

1. 把新的 jpg 放进 `I:\网页所需图片\`
2. 在 `照片索引说明.docx` 里加一行，格式：
   `文件名: 年.月: 地点：描述；拍摄器材：机身 + 镜头`
3. 英文说明写进 `assets/photography/captions-en.json`（照文件里已有条目的格式，键名＝文件名去掉扩展名）。**不写也能跑**——会退回用中文顶替，并在输出里提示你补。
4. 在项目目录里跑一次：

```bash
cd "C:/Users/28014/Documents/个人网页_江衍睿"
bash "更新摄影图库.sh"
```

脚本会：读说明文档 → 处理照片 → 重建 `site.html`（三 tab 应用页）里 `<!-- GALLERY:START -->` 与 `<!-- GALLERY:END -->` 之间的所有照片块 → 打印对账结果。

**可以反复跑**，只替换图库那一段，灯箱、页脚、其他 tab 都不会动（已验证三次连跑输出完全一致）。

ℹ️ 图库在 `site.html`（不是封面 `index.html`）。摄影 tab 页头现在只有「小标签 + 标题 + 创作自述」，照片数量与拍摄地那行小字**已删除**，因此**加照片后不需要再改页头**，跑脚本即可。

## 四、关于「不可下载」——说清楚能做到什么

页面上做了这几件事（都已实测生效）：

| 措施 | 效果 |
|---|---|
| 右键菜单 | 图库与灯箱内被拦截；页面其他区域不受影响 |
| 拖拽图片 | 已拦截，且 `img` 标了 `draggable="false"` |
| 图片本身 | `pointer-events:none`，鼠标事件落在覆盖层上，所以「图片另存为」菜单根本不会出现 |
| 选中复制 | `user-select:none`、`-webkit-touch-callout:none` |
| 文件本身 | 只有长边 ≤1800 的缩小文件，**且水印是烙进像素里的** |

**但必须如实说明**：浏览器里不存在真正的「禁止下载」。任何人打开开发者工具、或直接抓网络请求，都能拿到这些文件。所以真正的保护是**水印**——即使文件被拿走，水印也在画面上。这也是为什么水印是烙进文件而不是用 CSS 叠上去的。

如果你要更强的保护：
- **只放小图**（长边 1200 以下），让拿到的文件没有使用价值
- **加大水印**或**居中斜向平铺**水印（会明显影响观感，多数摄影师不做）
- **需要看大图时走服务端授权**（需要后端，不再是纯静态站）
